### Dependencias previas
- Node.js 20
- npm
### Cómo ejecutar el proyecto localmente
1. Clonar el repositorio en su máquina
2. Entrar a la carpeta que acaba de clonar con
    ```console
   cd Front-End-Proyecto-Final
   ```
3. Instalar las dependencias de npm con
   ```console
   npm install
   ```
> Instalará todas las dependencias de librerías, la primera ejecución puede demorar
4. Ejecutar el servidor local con
```console
npm run dev
```
  --Se creará un servidor Vite en un puerto local (Típicamente 5173), y ya se puede ver en el navegador
